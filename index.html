avant la séance

Une clé gratuite pour démarrer

Cette appli va chercher les bandes-annonces sur TMDB (The Movie Database), gratuit. Crée un compte, récupère ta clé API, colle-la ici — elle reste uniquement sur ton téléphone.

  1. Va sur themoviedb.org/signup (compte gratuit)
  2. Paramètres → API → demande une clé "Developer"
  3. Copie la clé ("API Key (v3 auth)") et colle-la ci-dessous
